# marginfi

> marginfi is a decentralized borrowing and lending protocol built on the Solana blockchain by mrgn labs. Users lend supported Solana tokens to earn yield and borrow against supplied collateral. There is no hosted REST API — integration is done on-chain through the marginfi-v2 Solana program using the official TypeScript and Rust (CLI) SDKs. This llms.txt was generated by the API Evangelist enrichment pipeline from the public developer surface; it is not published by marginfi.
